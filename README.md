# Lead Capture Dashboard – Backend

This is the backend API for the Lead Capture Dashboard project.
It is built as part of the MERN / Automation Developer screening assignment.

The backend provides APIs to create and fetch leads and triggers a webhook after a lead is created to simulate an automation workflow.

---

## Features

- Create lead API
- Get all leads API
- Get single lead by ID API
- Webhook trigger after successful lead creation
- Webhook success and failure handling

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
